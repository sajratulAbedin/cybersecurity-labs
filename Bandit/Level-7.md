# Bandit Level 7 → Level 8

## Goal
The password for the next level is stored in the file data.txt next to the word millionth

## Command Used

```
 cat data.txt | grep millionth
```

## Output

```
<password for level 8>
```

## Explanation

1. Used ` cat data.txt | grep millionth` This command finds and displays the lines in the file `data.txt` that contain the word "millionth".
 2. here we piping using grep command.grep command search a specific word from a text file
