# Bandit Level 3 → Level 4

## Goal

The password for the next level is stored in the only human-readable file in the inhere directory. Tip: if your terminal is messed up, try the “reset” command.
## Command Used

```
cd
ls -la
cat ./-file07

```

## Output

```
<password for level 5>

```

## Explanation
1. Used `ls` to list the files in the current directory.
2. Found a file named `inhere`.
3. used cd command accessed the inhere folder
4. used ls -ls command show all file and directory in the current directory including hidden file
5. used file ./* command used to determine and display the type of all file 
6. cat ./-file07 used to display text file
